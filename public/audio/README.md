# Menu audio

menu-select.mp3 is the Persona 5 menu selection clip supplied by Pedro.
Source supplied by the user: https://www.101soundboards.com/sounds/24015627-p5-menu-select-sound
Original game audio: ATLUS / SEGA. This project does not claim ownership of the recording.

Sound is off by default and can be enabled through SOUND ON / OFF.
The preference is saved locally when browser storage is available.
Playback starts only from a user interaction, at a restrained volume.
It applies to menu links, project selectors and Back to Menu.
No background music, hover or distinct cancel clip is included.
